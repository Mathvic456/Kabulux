# Map Blank Screen Fix

## Issues Identified and Fixed

### 1. **Region Management Issue** ✅ FIXED
- **Problem**: `initialRegion` only sets region on mount, so when `pickupLocation` is set later, the map doesn't update
- **Solution**: 
  - Added immediate region update when `pickupLocation` becomes available
  - Separated region updates into different useEffects for better control
  - Ensured region is calculated before map renders

### 2. **Map Initialization** ✅ FIXED
- **Problem**: Map might render before location data is available
- **Solution**:
  - Added `onMapReady` callback to ensure map centers when ready
  - Added `onError` callback to catch and display map loading errors
  - Improved logging for debugging

### 3. **Region Calculation Timing** ✅ FIXED
- **Problem**: Region calculation happened after map render
- **Solution**: Added immediate useEffect to update region when `pickupLocation` is available

## Code Changes Made

1. **Separated region updates**:
   - One useEffect for pickup-only case (immediate update)
   - One useEffect for pickup + dropoff case (with route calculation)

2. **Removed conflicting props**:
   - Removed `region` prop (was conflicting with `initialRegion`)
   - Using only `initialRegion` for uncontrolled map behavior

3. **Added error handling**:
   - `onError` callback to catch map loading errors
   - User-friendly error messages

## Common Causes of Blank Map

### 1. **API Key Not in AndroidManifest.xml** ⚠️ MOST LIKELY
The Google Maps API key needs to be in `android/app/src/main/AndroidManifest.xml`. This is auto-generated by Expo.

**Solution:**
```bash
npx expo prebuild --clean
# OR
npx expo run:android
```

This regenerates the native Android files with the API key from `app.config.js`.

### 2. **API Key Restrictions**
Check Google Cloud Console:
- API key restrictions might be blocking the app
- Ensure Android package name `com.crashingout.kablux` is allowed
- Ensure Maps SDK for Android is enabled

### 3. **Map Container Dimensions**
Ensure the parent container has proper dimensions:
```tsx
<View style={{ flex: 1 }}>  {/* ✅ Good */}
  <RideMapView ... />
</View>

<View style={{ height: 0 }}>  {/* ❌ Bad */}
  <RideMapView ... />
</View>
```

### 4. **Network/Permissions**
- Check device has internet connection
- Check location permissions are granted (if needed)

## Debugging Steps

1. **Check Console Logs**:
   ```javascript

   console.log('Map is ready, current region:', region);
   console.log('Updated region to pickup location:', newRegion);
   ```

2. **Check Map Container**:
   - Ensure parent View has `flex: 1` or explicit height
   - Check if map style has proper dimensions

3. **Verify API Key**:
   ```bash
   # Check .env file
   cat .env | grep GOOGLE_API_KEY
   
   # Should show:
   # EXPO_PUBLIC_GOOGLE_API_KEY=AIzaSyD5mNdwJg_TARwAw6OugmUFCo2_mnUTKqI
   ```

4. **Test API Key Directly**:
   ```bash

   ```

## If Map Still Blank

1. **Check AndroidManifest.xml**:
   ```bash
   cat android/app/src/main/AndroidManifest.xml | grep API_KEY
   ```

2. **Rebuild Native App**:
   ```bash
   npx expo prebuild --clean
   npx expo run:android
   ```

3. **Check Logcat** (Android):
   ```bash
   adb logcat | grep -i "maps\|google\|api"
   ```

4. **Verify MapView is Rendering**:
   - Add a background color to MapView style temporarily
   - If background shows but map doesn't = API key issue
   - If nothing shows = container/style issue
